Madar Randa — Style Guide

Reference for editing sections, tokens, and components. Open in browser alongside your code editor.

1 — Where to edit what

Navbar · Footer · Hero slider
Phone, links, CTA button text, hero slide images & text, stats, footer columns, legal line — all from one file.
js/config.js
Colors · Fonts · Spacing tokens
All CSS variables (--color-navy, --font-display, --section-pad, etc.) live here. Change once, applies everywhere.
css/tokens.css
Component styles
Buttons, cards, navbar, hero, breadcrumb, footer, badges, forms, animations. All visual rules.
css/styles.css
Navbar + Footer HTML structure
The JS that builds and injects the navbar, footer, hero slider, WhatsApp FAB, and back-to-top button.
js/components.js
Homepage content
Products grid, sectors, about preview, Vision/Mission cards, testimonials, FAQ, contact form.
index.html
Product detail content
Each product's title, description, features list, benefits, specs, applications — all products in one array.
js/app.js → SERVICES_DATA
About page
Story text, Vision card, Mission card, Values grid, Partners section, CTA.
about.html
Products listing page
Showcase cards (large alternating layout). Each card: image, number, eyebrow, title, body, tags, CTA.
services.html
Smooth scroll speed
duration = how long the glide lasts (seconds). wheelMultiplier = distance per scroll notch.
js/app.js → initLenis()
Breadcrumb / page hero height
min-height and max-height are both 40vh with !important. Safe to change both values together.
css/styles.css → .hero.hero--page

9 — Standard section structure

Copy this pattern for any new section in HTML pages
<section class="section section--pale" aria-labelledby="my-title">
  <div class="container">

    <!-- Optional: centred header -->
    <div class="section-header section-header--center">
      <span class="eyebrow">Eyebrow label</span>
      <h2 class="section-title" id="my-title">Section Heading</h2>
      <p class="section-subtitle">Optional subtitle text.</p>
    </div>

    <!-- Your content grid here -->

  </div>
</section>

Swap section--pale for any background class from §8 above.

10 — Quick reference: change one thing

Change the phone number js/config.js → contact.phone + contact.phoneTel
Change the logo js/config.js → logo.src
Change a nav link js/config.js → nav.links[ ]
Change hero slide image js/config.js → hero.slides[0].img
Change the accent color css/tokens.css → --color-accent
Change breadcrumb height css/styles.css → .hero.hero--page { min-height / max-height }
Change scroll slide feel js/app.js → initLenis() { duration, wheelMultiplier }
Change footer legal text js/config.js → footer.legalEn / footer.legalAr
Add a product to dropdown js/config.js → nav.links[0].dropdown[ ]
Change section spacing css/tokens.css → --section-pad
