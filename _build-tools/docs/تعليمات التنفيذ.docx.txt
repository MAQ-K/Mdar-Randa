2. تقسيم الصفحات ومنع التداخل
أبواب الكراجات: رول الكراجات السكنية + سيكشنال الأمريكي، ولا تُستهدف بها «أبواب رول للمحلات».
أبواب الشتر والرول: الشتر الصناعي، الشبك، المخرم، البولي كربونات الشفاف للمحلات والمصانع؛ دون تكرارها داخل صفحة الأبواب الصناعية.
الأبواب الصناعية ومعدات التحميل: الأبواب المقطعية الصناعية، PVC السريعة، المقاومة للحريق، الرافعات الهيدروليكية، وإطارات الربل. حدّد وضع صفحة معدات التحميل القديمة قبل تحويلها أو إبقائها.
صفحات مستقلة أيضًا: الأبواب الزجاجية، محركات البوابات، الحواجز والمواقف، شتر النوافذ، هناجر الطائرات، الصيانة، خدمة ما بعد البيع والضمان، الرئيسية، من نحن.
لكل صفحة مسار URL وCanonical وTitle وH1 خاص؛ الروابط الداخلية واضحة وفق الصلة، دون دمج الصفحات أو توجيه Canonical إلى صفحة خدمة أخرى.
حذف صفحة مشاريعنا من النسخة القديمة للموقع
التزم حرفيًا بـ Meta Title وMeta Description وH1/H2/H3 المعتمدة. H1 واحد لكل صفحة، ثم تسلسل منطقي للعناوين.
حافظ على صياغات الثقة المؤكدة: +30 سنة خبرة، +1000 مشروع منفذ، خدمة القصيم، الصيانة والدعم الفني وتوفر قطع الغيار.
ربط صفحات الصيانة والضمان والمنتجات ذات الصلة بروابط نهائية فعلية، لا روابط افتراضية أو placeholder.
نفّذ الصفحة وفق ملف المحتوى المعتمد المرفق دون تعديل علي عنوان أو منتج أو مواصفة، وفي حالة التعديل البسيط علي صياغة أي نص ليناسب UX الصفحة يجب الألتزام بالكلمات المفتاحية المرفقة مع كل ملف
استخدم الصور وأسماء الملفات والنصوص البديلة وبيانات Schema المعتمدة. يُسمح بإجراء التحسينات التقنية اللازمة للصور أو تصحيح أخطاء JSON-LD والروابط البرمجية دون تغيير المعلومات أو الادعاءات المعتمدة. وأي تغيير في المحتوى أو المواصفات يتطلب مراجعة مسبقة.
إذا وجدت معلومة ناقصة ضعها في قائمة أسئلة/نواقص ولا تخمّنها. سلّم الكود مع قائمة فحص توضح ما نُفّذ وما يحتاج اعتمادًا.
تحويل جميع صور الموقع إلى صيغة WebP وضغطها لتقليل حجم الملفات مع الحفاظ على جودتها البصرية ووضوح تفاصيل المنتجات
ملفات المحتوى المعتمدة لكل صفحة هي المرجع الوحيد للنصوص والعناوين وMeta والمنتجات وCTA. لا تعِد الكتابة أو تختصر أو تضف أقسامًا من تلقاء نفسك.
إذا غاب نص أو رابط أو مواصفة أو صورة، سجّله «مطلوب من العميل» ولا تُنشئ بديلًا تخمينيًا بالذكاء الاصطناعي.
لا تنقل منتجًا من صفحة إلى أخرى ولا تكرر كتل المنتجات. اعرض التغييرات خارج نطاق التنفيذ للمراجعة قبل اعتمادها.
اعتمد تصميمًا موحدًا للصفحات (Hero، شريط ثقة، بطاقات منتجات، مزايا/تشغيل، خطوات، مراجعات، FAQ، CTA) مع اختلاف المحتوى حسب الصفحة.
تقليل ملفات JavaScript وCSS غير الضرورية.
