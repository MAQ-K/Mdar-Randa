# مدار راندا — دليل رفع النظام
## تسليم لإدارة مدار راندا

---

## نظرة عامة

النظام يتكوّن من **ثلاثة أجزاء**:

| # | الملف | الوظيفة | يُرفع على |
|---|-------|---------|-----------|
| 1 | `server.js` | الخادم (Backend) — يرسل الرسائل عبر تقنيات | Node.js hosting |
| 2 | `client-portal.jsx` | بوابة العملاء | `madaranda.com` |
| 3 | `staff-app.jsx` | تطبيق الموظفين (إدارة/مشرف/فني) | `madaranda.com/staff` |

**مبدأ الأمان المهم:** توكن تقنيات موجود **فقط** في `server.js` (الخادم)، ولا يظهر أبداً في كود الواجهة. كل الرسائل تمر عبر الخادم.

---

## الجزء الأول: رفع الخادم (server.js)

### المتطلبات
- استضافة تدعم **Node.js** (مثل: خادم VPS، أو خطة Node على cPanel)
- إذا الاستضافة الحالية ما تدعم Node، استخدم خدمة مثل Railway أو Render (مجانية للبداية)

### الخطوات
```bash
# 1. ثبّت المكتبات
npm install express cors

# 2. شغّل الخادم
node server.js
```

الخادم يعمل على المنفذ `3001` افتراضياً.

### إعدادات تقنيات (موجودة جاهزة في الملف)
```js
const TAQNYAT_TOKEN = "3059c140d4c1d87d5ce1ddbb3ba61c6d";
const SENDER_NAME   = "MRanda";
```

### نقاط الاتصال (API) الجاهزة
| Method | المسار | الوظيفة |
|--------|--------|---------|
| POST | `/api/send-otp` | إرسال رمز تحقق للعميل |
| POST | `/api/verify-otp` | التحقق من الرمز |
| POST | `/api/requests` | إنشاء طلب + SMS تأكيد |
| GET | `/api/requests` | جلب كل الطلبات |
| GET | `/api/requests/phone/:phone` | طلبات عميل معيّن |
| POST | `/api/requests/:id/assign` | إسناد لمجموعة + OTP إغلاق |
| POST | `/api/requests/:id/close` | إغلاق الطلب بـ OTP |
| POST | `/api/requests/:id/suspend` | تعليق الطلب |

## الجزء الثاني: بوابة العملاء (client-portal.jsx)

### مكان الرفع
الصفحة الرئيسية: **`madaranda.com`**

### ⚠️ مهم قبل الرفع
في أعلى `client-portal.jsx` غيّر عنوان الخادم:
```js
const API_BASE = "https://madaranda.com/api";
```
اجعله يطابق عنوان الخادم الذي رفعته في الجزء الأول.

### ماذا تفعل البوابة
- العميل يدخل بياناته + رقم جواله
- يضغط "إرسال رمز" → الخادم يرسل OTP عبر تقنيات
- يتحقق من الرمز → يكمل الطلب
- تتبع الطلبات برقم الجوال

### ميزة تبديل اللغة
زر (EN / ع) في أعلى يمين الصفحة يبدّل بين العربية والإنجليزية — يشمل جميع النصوص واتجاه الصفحة (RTL/LTR). اللغة الافتراضية عربي.

### ملف index.html للبوابة

## الجزء الثالث: تطبيق الموظفين (staff-app.jsx)

### مكان الرفع
رابط خاص للموظفين فقط: **`madaranda.com/staff`**

> ملاحظة: هذا الرابط لا يُعلن للعملاء. الموظفون فقط يعرفونه.

### نظام تسجيل الدخول
صفحة دخول واحدة، وكل موظف حسب حسابه يُوجّه لصفحته:

| النوع | يشوف |
|-------|------|
| الإدارة | إحصائيات + طلبات + فنيين + مجموعات + **إدارة المستخدمين** |
| المشرف | إنشاء طلبات + إسناد + إدارة فنيين ومجموعات + **تقرير يومي قابل للطباعة** |
| الفني | طلبات مجموعته فقط + إغلاق الطلب بـ OTP |

### ميزة تبديل اللغة
زر (EN / ع) في الهيدر وفي شاشة الدخول يبدّل كل نصوص التطبيق بين العربية والإنجليزية، بما في ذلك التقرير المطبوع واتجاه الصفحة (RTL/LTR).

### ميزة التقرير اليومي (للمشرف)
- المشرف يختار أي تاريخ من تبويب "تقرير يومي"
- يشوف معاينة: إحصائيات اليوم + قائمة الطلبات
- زر "طباعة التقرير" يفتح صفحة طباعة رسمية تشمل: شعار الشركة، جدول الطلبات الكامل، الإحصائيات، وخانات توقيع المشرف واعتماد الإدارة

### الحسابات الأولية
| النوع | المستخدم | كلمة المرور |
|-------|----------|-------------|
| الإدارة | admin | admin123 |
| المشرف | super | super123 |
| فني Kalam | kalam | kalam123 |
| فني Bateel | bateel | bateel123 |
| فني Joji | joji | joji123 |
| فني Manoosh | manoosh | manoosh123 |

> الإدارة تقدر تغيّر أي اسم مستخدم أو كلمة مرور من تبويب "المستخدمين".

### ملف index.html للموظفين
نفس ملف HTML أعلاه، بس غيّر:
- العنوان إلى: `مدار راندا - الموظفين`
- السطر الأخير إلى: `<script type="text/babel" src="./staff-app.jsx"></script>`

### ربط تطبيق الموظفين بالخادم
تطبيق الموظفين حالياً يعمل ببيانات داخلية (للعرض). لربطه بالخادم الحقيقي:
- استبدل البيانات الأولية (`INITIAL_REQUESTS`) باستدعاء `GET /api/requests`
- عند الإسناد، استدعِ `POST /api/requests/:id/assign`
- عند الإغلاق، استدعِ `POST /api/requests/:id/close`

## ملاحظات مهمة

### 1. قاعدة البيانات
الخادم حالياً يحفظ الطلبات **في الذاكرة** (تُمسح عند إعادة التشغيل). للحفظ الدائم:
- اربط بقاعدة بيانات (MySQL أو MongoDB)
- استبدل مصفوفة `requests` في `server.js` بجداول قاعدة البيانات

### 2. الأمان
- ✅ توكن تقنيات محفوظ في الخادم فقط (آمن)
- 🔒 يُفضّل تفعيل HTTPS على الدومين
- 🔒 كلمات المرور حالياً نصية — للإنتاج الجدّي يُفضّل تشفيرها (bcrypt)

### 3. الشعار
الشعار مدمج داخل ملفات JSX (base64)، ما يحتاج ملف صورة منفصل.

## خلاصة خطوات الرفع

1. ☐ ارفع `server.js` على استضافة Node.js وشغّله
2. ☐ عدّل `API_BASE` في `client-portal.jsx` و `staff-app.jsx`
3. ☐ ارفع `client-portal.jsx` + index.html على `madaranda.com`
4. ☐ ارفع `staff-app.jsx` + index.html على `madaranda.com/staff`
5. ☐ جرّب: أنشئ طلب من البوابة وتأكد وصول SMS
6. ☐ (لاحقاً) اربط بقاعدة بيانات للحفظ الدائم
