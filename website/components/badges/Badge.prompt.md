Compact label for sector tags, certification status, and project classifications.

```jsx
// Sector tags on project cards
<Badge variant="primary">Aviation</Badge>
<Badge variant="accent">Commercial</Badge>
<Badge variant="silver">Industrial</Badge>

// Status indicators
<Badge variant="success">✓ Certified</Badge>
<Badge variant="accent" dot>Active Contract</Badge>
<Badge variant="warning">Pending Review</Badge>

// On dark navy backgrounds
<Badge variant="on-dark">30+ Years</Badge>
<Badge variant="on-dark">500+ Projects</Badge>
```

Variants: primary (navy fill), accent (blue tint), outline, silver, success, warning, danger, on-dark
